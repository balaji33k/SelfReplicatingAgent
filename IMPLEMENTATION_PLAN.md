# Implementation Plan: Multi-Agent Specialization
## Self-Replicating Coding Agent — Gen 1 → Gen N

---

## The Prime Directive

**Every offspring must be designed from scratch. No file from the parent may be copied into the next generation.**

This is not a style preference. It is the structural guarantee that makes the system evolutionary rather than reproductive. A system that copies its parent is not improving — it is cloning. Clones do not evolve.

This directive governs every phase of this plan:
- Every agent file must be LLM-generated in full on every spawn
- The spawner aborts with a hard error if any required file is missing
- The evolution prompt explicitly shows current source and labels it "STUDY — DO NOT COPY"
- The topology config must also be regenerated — not carried forward
- Infrastructure files (telemetry.py, lineage_memory.py) are the only exception — they are never generated by the LLM

---

## Strategic Decision

**Implement directly in `gen_1` + update `seed_prompt.txt`.**

Gen 1 becomes the first multi-agent organism, built with full quality control.
The evolutionary engine knows to regenerate all agent files in every offspring.
The seed prompt encodes multi-agent principles so any future re-bootstrap produces the same architecture.

## Phase 1 — Data Contracts (`contracts.py`)

Defines every typed object passed between agents. No logic — pure data structures.

```
AnalysisSpec
  task_id        : str
  problem_type   : str        # "algorithm" | "bug_fix" | "optimization" | "unknown"
  input_types    : List[str]
  output_type    : str
  constraints    : List[str]  # "O(n log n) required", "no built-in sort", etc.
  edge_cases     : List[str]  # empty list, negatives, overflow, etc.
  success_criteria: str

DesignSpec
  task_id              : str
  algorithm            : str        # name + one-line rationale
  data_structures      : List[str]
  steps                : List[str]  # pseudocode — numbered, unambiguous
  complexity           : str        # time + space
  edge_case_strategies : Dict[str, str]  # edge_case → how to handle

CritiqueReport
  task_id          : str
  passed           : bool           # True = no issues found
  logic_errors     : List[str]
  edge_cases_missed: List[str]
  spec_deviations  : List[str]
  suggested_fixes  : List[str]      # targeted, not rewrites

PipelineResult
  task_id        : str
  success        : bool
  final_code     : str
  error_type     : Optional[str]
  agents_used    : List[str]
  cycles         : Dict[str, int]   # {"reviser": 1, "debugger": 0}
  agent_failures : Dict[str, str]   # {"critic": "missed logic", ...}
```

**No-copy implication:** The contracts themselves are regenerated by the LLM in
every offspring. If Gen 2's experience reveals that `AnalysisSpec` should carry
a `severity_score` per constraint, Gen 2's LLM writes a new `contracts.py` from
scratch — it does not inherit Gen 1's version.

## Phase 3 — The 7 Specialist Agents

Each agent file has one class, one `run()` method, one internal prompt.
No central `prompts.py` — each agent owns its reasoning strategy.

### Information Isolation Rules (enforced in code, not just convention)

| Agent | Receives | Forbidden From Receiving |
|---|---|---|
| `agent_analyst.py` | Raw `Task` | Any prior agent's output |
| `agent_architect.py` | `AnalysisSpec` | Raw task, test cases |
| `agent_coder.py` | `DesignSpec` + `AnalysisSpec` | Raw task, test cases |
| `agent_critic.py` | `code` + `AnalysisSpec` | `DesignSpec` (no design bias) |
| `agent_reviser.py` | `code` + `CritiqueReport` | `AnalysisSpec` (targeted fixes only) |
| `agent_test_writer.py` | `AnalysisSpec` **only** | **The code** (no implementation bias) |
| `agent_debugger.py` | `code` + `ExecutionResult` | `DesignSpec`, `AnalysisSpec` |

The `agent_test_writer.py` never seeing the code is the most critical isolation.
A test writer who has read the implementation tests the implementation, not the spec.

### Responsibilities

**`agent_analyst.py`**
- Reads the raw problem statement
- Identifies: problem type, input/output types, constraints, edge cases
- Produces `AnalysisSpec` — a structured decomposition of the problem
- Does NOT suggest any solution or algorithm

**`agent_architect.py`**
- Receives `AnalysisSpec`
- Selects an algorithm with explicit reasoning
- Produces `DesignSpec` — step-by-step pseudocode with complexity
- Does NOT write any Python code

**`agent_coder.py`**
- Receives `DesignSpec` + `AnalysisSpec`
- Translates design into clean Python — no reasoning, just implementation
- Follows the pseudocode steps exactly
- Does NOT re-evaluate the problem

**`agent_critic.py`**
- Receives code + `AnalysisSpec` (not `DesignSpec` — no design bias)
- Adversarially tries to find bugs: logic errors, missed edges, spec deviations
- Produces `CritiqueReport` with `passed: bool`
- Does NOT rewrite the code

**`agent_reviser.py`**
- Receives code + `CritiqueReport`
- Makes only the targeted fixes the Critic specified
- Does NOT invent new requirements or redesign the algorithm
- Limited to `max_revise_cycles` iterations (configurable)

**`agent_test_writer.py`**
- Receives `AnalysisSpec` only — NEVER the code
- Writes boundary tests, negative tests, large-input tests not in the pool
- Returns `List[Dict]` — same format as `task.test_cases`
- Its tests are independent evidence of correctness

**`agent_debugger.py`**
- Receives code + `ExecutionResult` (the actual error output)
- Diagnoses root cause from the error message and code
- Writes a targeted patch
- Does NOT redesign the algorithm

**No-copy implication:** All 7 agent files must be regenerated on every spawn.
The evolution engine's prompt includes all 7 current agent files labeled
"STUDY — DO NOT COPY". Gen 2's Critic might use a completely different
adversarial strategy. Gen 3's Architect might produce richer pseudocode.
None of this is possible if files are carried forward unchanged.

## Phase 4 — Pipeline Orchestrator (`pipeline.py`)

Reads the topology from `AgentTopologyConfig` and executes agents as a directed graph.
The sequence is data-driven — not hardcoded `if/else` chains.

```
AgentPipeline.solve(task: Task) → PipelineResult:

  1. analysis   = Analyst.run(task)
  2. design     = Architect.run(analysis)
  3. code       = Coder.run(design, analysis)

  4. critique   = Critic.run(code, analysis)
     WHILE not critique.passed AND revise_cycles < max_revise_cycles:
         code      = Reviser.run(code, critique)
         critique  = Critic.run(code, analysis)
         revise_cycles++

  5. extra_tests = TestWriter.run(analysis)     ← NEVER receives code

  6. result     = Executor.run(task, code, all_tests=task.test_cases + extra_tests)

     IF not result.success AND debug_cycles < max_debug_cycles:
         code   = Debugger.run(code, result)
         result = Executor.run(task, code)

  7. return PipelineResult(
         success=result.success,
         final_code=code,
         agents_used=[...],
         cycles={"reviser": revise_cycles, "debugger": debug_cycles},
         agent_failures={...}
     )
```

**No-copy implication:** `pipeline.py` must be regenerated on every spawn.
Gen 2 might reorder agents. Gen 3 might run two Critics in parallel and take
a majority vote. Gen 4 might make the Architect consult the TestWriter before
finalizing the design. None of this evolution is possible if `pipeline.py` is
copied from the parent.

## Phase 5 — Config Extension (`config.py`)

Add `AgentTopologyConfig` — the evolvable topology descriptor.

```python
class AgentTopologyConfig:
    enabled_agents    : List[str]   # which agents are active
    agent_order       : List[str]   # execution sequence
    max_revise_cycles : int = 2     # Critic → Reviser loop cap
    max_debug_cycles  : int = 1     # Executor → Debugger loop cap
    critic_persona    : str = "adversarial"   # or "constructive"
    parallel_critics  : int = 1     # future: N critics, consensus vote
```

`Config` gains: `self.agent_topology = AgentTopologyConfig()`

**No-copy implication:** `config.py` is in `REQUIRED_LOGIC_FILES`. The LLM
must generate it fresh every spawn. The `AgentTopologyConfig` it contains
is the topology the LLM designed for that generation — not inherited.

## Phase 6 — Main Orchestrator Update (`main.py`)

Replace the single `CodeGenerator + SandboxExecutor` loop:

```python
# BEFORE — one generalist LLM call per task:
for task in tasks:
    code   = code_generator.generate_solution(task)
    result = sandbox_executor.execute_code(task, code)

`cycles`, and `agent_failures`. The rest of `main.py` (analysis, evolution,
spawning) reads `PipelineResult` the same way.

SECTION 2 — ALL files in delimited blocks:

=== END filename.py ===

Required files (ALL must be present or spawn aborts):

agent_test_writer.py, agent_debugger.py, pipeline.py,
sandbox_execution.py, analysis.py, evolution_engine.py, spawner.py
```

### Topology Evolution Logic

The evolution engine's prompt includes instructions for when to evolve the topology:

```
TOPOLOGY EVOLUTION INSTRUCTIONS

If critic missed logic errors in > 30% of failures:
  → Add a second Critic with a different adversarial persona
  → Or make the Critic run two passes with different framings

If coder syntax errors > 20% of failures:
  → Insert a Compiler/Linter agent after Coder, before Critic

If debugger hit rate < 20%:
  → Consider removing Debugger, extending Reviser cycles instead

If test_writer catches > 25% of failures the pool missed:
  → Increase test_writer budget (more test cases generated)

If all agents show low failure rates but pass rate is still low:
  → The bottleneck is the Architect — redesign DesignSpec format
  → Or add a Complexity Estimator between Analyst and Architect

You MAY invent new agent types if failure patterns demand it.
Any agent_*.py file you create will be written to disk.
Any agent_*.py file you omit will cause spawn to abort.
```

### No-Copy Guard — Hard Enforcement

```python
def _validate(self, new_files: Dict[str, str]) -> None:

    # 1. All required files must be LLM-generated
    missing = [f for f in REQUIRED_LOGIC_FILES if f not in new_files]
    if missing:
        raise RuntimeError(
            f"SPAWN ABORTED — No-Copy Violation.\n"
            f"LLM did not generate: {missing}\n"
            f"Every required file must be fully generated. "
            f"Copying parent files is forbidden."
        )

    # 2. Every generated file must compile
    compile_errors = []
    for fname in REQUIRED_LOGIC_FILES:
        try:
            ast.parse(new_files[fname])
        except SyntaxError as e:
            compile_errors.append(f"{fname}: {e}")
    if compile_errors:
        raise RuntimeError(
            f"SPAWN ABORTED — Compile errors in generated files:\n"
            + "\n".join(compile_errors)
        )

    # 3. No file may be identical to the parent's version
    gen_dir = Path(__file__).resolve().parent
    clone_files = []
    for fname, content in new_files.items():
        parent_path = gen_dir / fname
        if parent_path.exists():
            parent_content = parent_path.read_text(encoding="utf-8")
            if content.strip() == parent_content.strip():
                clone_files.append(fname)
    if clone_files:
        raise RuntimeError(
            f"SPAWN ABORTED — No-Copy Violation.\n"
            f"Files identical to parent: {clone_files}\n"
            f"The LLM must redesign every file based on failure evidence."
        )
```

The third guard — **identical content check** — is the structural guarantee
that no silent clone can pass through. Even if the LLM generates the file name,
if the content is unchanged, spawn aborts.

## Phase 10 — Seed Prompt Update (`seed_prompt.txt`)

The seed prompt gains two new sections and a strengthened guardrail.

### New Section: MULTI-AGENT PIPELINE GUIDELINES

```
MULTI-AGENT PIPELINE GUIDELINES
---------------------------------
Benchmark solving must use a pipeline of specialist agents — not a single LLM call.
Each agent has one cognitive responsibility and produces one structured output.
No agent performs a task outside its designated role.
The pipeline topology is config-driven and must be evolvable.

Minimum required agents:
  Analyst      — decomposes problem into AnalysisSpec (never writes code)
  Architect    — designs algorithm strategy into DesignSpec (never writes code)
  Coder        — translates DesignSpec into Python (never re-analyzes)
  Critic       — adversarially reviews code against AnalysisSpec
  Reviser      — applies targeted fixes from Critic only
  TestWriter   — writes tests from AnalysisSpec ONLY — must never see the code
  Debugger     — diagnoses execution failures and patches code

Information isolation (enforced in pipeline.py, not just convention):
  TestWriter must never receive code as input — only AnalysisSpec
  Critic must not be the author of the code it reviews
  Architect must not see raw test cases — only AnalysisSpec
  Debugger receives only the error and the code — not the design

The topology (which agents, in what order, with what cycle limits) lives in
AgentTopologyConfig inside config.py. The evolutionary engine must propose
a new topology alongside new code on every spawn — never carry it forward.
```

### New Section: NO COPYING OFFSPRING GENERATION

```
NO COPYING OFFSPRING GENERATION
---------------------------------
Each offspring must be designed from scratch based on failure evidence.
This is the prime directive of the system.

Concrete enforcement requirements:
  The spawner must maintain a list of ALL required logic files.
  The spawner must ABORT with RuntimeError if any required file is missing.
  The spawner must ABORT with RuntimeError if any generated file is
    identical to the parent's version of that file.
  No shutil.copy, shutil.copytree, or file-read-then-write pattern
    may be used for logic files — only for infra (telemetry, lineage_memory).

The evolution engine's synthesis prompt must:
  Include the FULL source of ALL current files, labeled "DO NOT COPY".
  Explicitly instruct the LLM to redesign every file from scratch.
  Identify which agents failed and require those agents to be redesigned.
  Require ALL logic files to appear in the output — partial responses abort.

The test for whether a generation is truly evolutionary (not reproductive):
  If you removed the parent's code from the LLM prompt, would the offspring
  still be better? If yes — the offspring is evolutionary.
  If no — the offspring is a copy with minor edits, and the system has stagnated.
```

### Strengthened Existing Guardrail

```
No Copying (strengthened):
  The next generation must never be a copy or near-copy of the current generation.
  Every component must be redesigned based on failure evidence — not carried forward.
  The spawner enforces this structurally:
    — Aborts if any required file is missing from LLM output
    — Aborts if any generated file is content-identical to the parent's file
    — Never copies logic files as fallback under any circumstance
  Copying parent files is not a fallback strategy — it is a spawn failure.
  The LLM must generate everything or the spawn does not happen.
```

## What Changes Per Generation

| Generation | Topology | Why |
|---|---|---|
| Gen 1 | 7 agents, fixed (manual) | Baseline — full quality control |
| Gen 2 | 7 agents, evolved prompts | Critic + Coder prompts refined from agent_failures |
| Gen 3 | 8–9 agents | LLM adds Complexity Estimator or dual Critics based on data |
| Gen 4+ | Unknown | Emergent — topology evolves under selection pressure |

The topology is not designed to converge. It is designed to keep diverging under
pressure — exactly as biological specialization kept diverging under predation,
climate, and resource pressure over hundreds of millions of years.

## Summary of No-Copy Enforcement Points

| Location | Mechanism | Effect of Violation |
|---|---|---|
| `spawner.py` — missing file check | RuntimeError | Spawn aborts entirely |
| `spawner.py` — identical content check | RuntimeError | Spawn aborts entirely |
| `spawner.py` — no shutil.copy for logic | Code structure | No fallback path exists |

| `seed_prompt.txt` — NO COPYING section | Foundation prompt | Every bootstrapped gen inherits the rule |
